The insight

Escrow was never the hard part.
The judge was.

A neutral judge that reads the agreement, looks at the work and decides — cheaply, quickly, with receipts. In 2026 an LLM can be that judge, if you give it a contract written to be checked, evidence computed by code, and a payment rail that can pay, refund or split.

How it works

From DM to paid, in five steps.

1

Compile

Paste the chat → milestones and machine-checkable criteria. Vague terms rewritten, scam signals flagged.

2

Seal & fund

Both sign. Client funds each milestone with PayPal Checkout; money held in escrow.

3

Deliver & judge

Evidence engine measures files, links and repos; the AI referee rules per criterion with citations.

4

Settle

Approve → PayPal Payout. Dispute → AI-mediated split as Payout + partial refund. Reject → human.

5

No ghosting

Client silent past the window? Passing work auto-releases; failing work goes to mediation.

+

Agents hire too

MCP server: AI agents create pacts, get PayPal approval links for humans, submit work, read verdicts.

The product

Every ruling shows its work.

A score computed in code, a result per criterion, the exact evidence quoted, machine checks that override the model — and a red flag when a deliverable tries to talk to the referee.

AI you can put next to money

Code measures. The model judges.
People decide.

Deterministic evidence

Word counts, live links, page contents, repo paths, image sizes, PDF/DOCX text — computed by code and authoritative over the model.

Injection-proof

Untrusted content is fenced; a scanner reads text hidden from humans. Manipulated deliverables never auto-release.

Humans hold the pen

The mediator only proposes. Both parties must accept a split, or it escalates to a human arbitrator.

From sandbox to production

PayPal holds the money.
Kept holds the judgment.

In production Kept runs on PayPal's multiparty platform with delayed disbursement: freelancers onboard via Partner Referrals, orders name the freelancer as payee with disbursement_mode: DELAYED, and Kept releases with referenced payouts. PayPal holds funds; Kept never touches them — no money-transmitter licensing, escrow pre-approval as PayPal's AUP requires.
